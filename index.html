Frequently asked questions

Are the tools on Tool360 really free?

Yes. Every live tool is free to use with no account and no usage counter. The tools run on your own device, so there is no server bill to pass on to you.

Are my files uploaded to a server?

No. Tool360 processes files locally in your browser using JavaScript. Your PDFs and images never leave your device, and closing the tab removes everything from memory.

Do I need to install anything?

No installation and no browser extensions. Any modern browser on desktop or mobile can run every tool on this site.

Is there a limit on file size or number of uses?

There are no accounts, quotas or daily limits. Because everything is processed on your own device, the only practical limit for very large files is your device’s memory — for everyday documents and images you will not notice one.

How can I find a tool quickly?

Press Ctrl + K (or Cmd + K on a Mac) anywhere on the site to open the search palette, or tap the star on any tool card to pin it to your favourites on this page.
